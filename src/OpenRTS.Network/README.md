# OpenRTS.Network

Основа сетевого модуля OpenRTS, .NET 10 / MIT. Проект включён в решение и обычную сборку. Runtime API, транспорт и сетевой матч пока не реализованы.

Здесь будут протокол, обмен командами, координация сетевых тиков, диагностика синхронизации и затем репликация разрешённых игроку данных. Первая версия — прямое подключение двух клиентов, полная симуляция на обоих. Поздняя версия — доверенный сервер симуляции и клиентское представление по отфильтрованным наблюдениям.

Направление зависимости: Network → Gameplay → Core. Существующие публичные namespaces Gameplay `OpenRTS.Core.*` не означают зависимость только от сборки Core. Модуль не зависит от Godot, YAML/Content, sandbox или AI; definitions и настройки матча готовит потребитель. Core/Gameplay не ссылаются на Network. Отдельные серверные приложения и сервис поиска матчей появятся с работающим потребителем, а не как пустые проекты.

По прямому поручению пользователя создан только этот каркас. Типы сообщений и абстракции транспорта появятся в первом проверяемом срезе; классов-заглушек и новых NuGet-зависимостей нет.
