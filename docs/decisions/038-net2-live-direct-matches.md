# 038. NET2: live direct match в Godot

**Дата:** 16 ноября 2026. **Статус:** исторический LAN/UI срез NET2; строгий barrier и format2 заменены [WAN-решением039](039-net2-wan-pipeline.md). Действующий protocol/journal —3. [План](../research/networking/roadmap.md) · [проверки](../verification/038-net2.md).

## Основной режим

Полный мир считается обоими клиентами. Внешний сервер не нужен. TLS аутентифицирует endpoint хоста по переданному отдельно отпечатку и шифрует соединение; это не удостоверяющий игровой сервер, не проверка честности клиента и не защита скрытого мира. Поздний защищённый режим NET8/NET9 не реализован и не требуется.

`DirectSession` владеет потоком, listener/socket/TLS, фабрикой мира, bounded вводом и событиями, FrameExchange и потоковым журналом. Подключение и TLS ограничены минутой и отменяемы. Хост создаёт временный ECDSA-сертификат на один день, показывает SHA-256 fingerprint. Join требует64hexсимвола и сравнивает fingerprint полученного сертификата точно, без режима «доверять любому сертификату». Host identity следует проверять по внешнему каналу. Клиентский сертификат/аккаунт не требуются; хост принимает одного подключившегося участника, а не удостоверяет его личность.

Один owner thread вызывает Step. UI Submit не меняет мир; очередь≤256команд. Batch≤256команд и≤32768recipients суммарно, при переполнении recipient budget оставшийся ввод переносится на следующий batch. Поток событий≤65536, превышение останавливает матч, не теряя события молча. Кадр копируется на owner; медленный renderer не блокирует Step. Интерполяция использует timestamp опубликованного кадра.

## Темп, окончание и протокол2

`MatchDescriptor.EndTick=0` означает live матч. Realtime pacing задаёт минимум одного фиксированного периода перед очередным тиком; сетевое ожидание не создаёт неограниченного долга catch-up и не меняет игровую длительность тика. Отмена по-прежнему делает прерванный внутри Step мир непубликуемым.

Сохранён строгий NET1 barrier: обмен batch и сравнение полного hash на каждом тике. Это полезно для LAN/диагностики, но задержка зависит от RTT. InputDelay ещё не превращён в полноценный асинхронный WAN pipeline; периодические hashes, измерение input→apply/display и WAN impairment tests остаются дальнейшей работой NET2. Не обещается25Гц при любом RTT.

Команда Leave — отдельный сетевой control frame на границе batches: оба peers завершают на одном уже подтверждённом тике и дописывают success footer журнала. Это завершение прямого матча, не механика победы/поражения или передачи армии ИИ. Аварийный выход/EOF/timeout останавливает второго участника с ошибкой; миграция/продолжение без игрока — NET3/4. Timeout выделен отдельно от пользовательской отмены.

Wire major2 и journal format2 несовместимы с NET1 version1. Собственные wire IDs первых6intents сохранены, добавлены все разрешённые текущей PlayerCommands приказы: одиночное движение, repair/capture/abilities/autocast, production/placement/rally, transport/construction/upgrade/transform, flight/contact attack, aim/clear aim. Передаются Action/Queue (≤128UTF-8bytes), Amount/Repeat/Enabled/TaskId, Owner в разрешённых случаях, QuarterTurns/TransformHere/ContactId. Admin spawn/remove/terrain/condition/visual commands не допускаются. Unsupported поля отвергаются, неизвестные IDs и неканонические booleans/recipients — ошибка. Игровая допустимость, ownership и target visibility проверяются Gameplay на согласованном тике.

Replay format2 допускает завершение раньше EndTick по согласованному Leave, а для live читает до явного success footer. Квота64MiB остаётся; при её исчерпании матч прекращается с диагностикой. Полного save/restore и автоматической ротации журнала нет.

## Godot-потребитель

Экран настройки предлагает local/host/join, адрес, порт, поле pin. Прямая игра ограничена двумя людьми без ИИ. Оба клиента выбирают одинаковые карту, starting set/slots, fog и игровые настройки; «Начать матч» — подтверждение готовности. Handshake сравнивает descriptor и полный hash мира0; распространения настроек лобби от хоста пока нет. MapMatch.Seed даёт реальный seed для descriptor, UnitCatalog fingerprint — identity контента; initial world hash дополнительно проверяет terrain/размещение/настройки.

UI показывает соединение/ожидание/завершение, позволяет отменить подключение и повторить. При разрыве начатого матча показывает причину и кнопку возврата к настройке. Хост копирует fingerprint из read-only поля, join вводит его перед запуском. Поля сети скрыты в offline режиме. Выбор/приказы привязаны к player1(host)/player2(join), в том числе при выключенном fog. F8 не переключает владельца сети. Локальное меню не приостанавливает мир, debug restart/playback/single-step/visual cheats отключены; обычные UI приказы проходят через сетевую очередь. «Покинуть матч» выполняет Leave; закрытие программы отменяет owner и закрывает socket.

`SandboxSession` — конкретный мост существующих offline/network потребителей sandbox. Offline Session API сохранён. Общая `SimulationSession.ToCommand(UnitAction)` используется обеими ветвями, чтобы не дублировать mapping игровых действий. Godot/Content не добавлены в Network.
