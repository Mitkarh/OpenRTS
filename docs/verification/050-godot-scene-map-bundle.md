В ходе проверки два общих Control получили локальные пути Godot при сборке Sandbox. Это устранило обращения из PCK к C# файлам вне проекта. Сборка подписанного приложения требует отдельного установленного export template и в этой среде не проверялась.

Полный набор Gameplay и Network в этом срезе не запускался.

## Управление playtest и экспорт P1

19 ноября 2026, macOS arm64, Godot 4.7.2 .NET. `verify-authoring` прошёл 252 проверки сцен и 145 проверок редактора. Запуск 2D и 3D дошёл до игрового кадра. Перезапуск завершил старый процесс и сохранил параметры матча. Проверены остановка, отмена ожидающего перезапуска, код выхода и сообщение о недостающей текстуре, а также остановка при отключении addon. Штатная остановка записываемого матча сохранила журнал повтора.

`verify-map-export` проверил чистый импорт с отключённым addon, отказ при отсутствии `SceneDecoration.gd` и запуск из изолированного PCK. Оба установленных bundle прошли проверку из меню. В тесте B5 сохранились начальное HP, локальный MaxHealth и поворот здания. Для 2D карты «Скалистый перевал» запуск из проекта и PCK дал шесть объектов и одинаковый хеш на тике 8. Проверка относится к PCK и сборкам ExportRelease на macOS arm64.
