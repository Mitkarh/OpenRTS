# Проверки B6

18 ноября 2026. Godot .NET 4.7.2, локальные процессы на macOS, сетевые клиенты соединены через TLS на loopback.

| Проверка | Результат |
|---|---|
| `OpenRTS.sln` и `OpenRTS.Network.Tests` | Сборка без предупреждений. 83 сетевые проверки прошли, включая чтение старых параметров, повреждённые и незавершённые журналы, отмену, квоты, возвращение в матч и B6-регрессию |
| B5 как 3D bundle | Два Godot-клиента подтвердили один игровой отпечаток и финальный хеш. Godot и отдельный headless-процесс воспроизвели итог на тике 35 |
| B5 как нативная изометрическая 2D compiled map | Та же процедура с независимо пересобранной картой. Оба формата прошли Ready/Start, игровые приказы, завершение, воспроизведение и проверку финального хеша |
| M1 «Долина» | Повторили тот же сетевой и replay-сценарий с YAML |
| Локальная запись из параметров редактора | Изометрический B5 с выбранным западным стартом. Итог на тике 12 совпал в Godot и headless. Сетевые сокеты этой записи не используются |
| «Скалистый перевал» | Локальный fixture с фиксированной расстановкой записан и воспроизведён до тика 12 в обоих хостах. Обычный headless также запустил его напрямую без сборки Network |
| Смена версии карты или стартового набора | TLS-клиент с изменённым HP при прежнем ID карты отказался до старта. Оба потребителя повтора отказались открывать изменённую карту. Headless также отказался воспроизводить повтор со стартовыми кредитами другой версии |
| Изменение только оформления | Автоматический тест использовал пересобранную проекцию с иным визуальным слоем и неизменным игровым отпечатком. Повтор дошёл до исходного хеша |

Сквозной прогон проверяет паузу, шаг, скорость, POV игрока, переход вперёд и назад, запуск с начала и запрет ввода в повторе. Отправка неподдерживаемого локального приказа и превышение лимита пакета проверяются отдельной регрессией. Положительные результаты относятся к указанным картам и локальной сети.

```sh
./tools/dev.sh map-build res://examples/maps/InitialPropertiesMapIsometric.tscn --verify
./tools/dev.sh verify-replay --map=res://artifacts/maps/initial-properties-isometric.ortmap.json
./tools/dev.sh verify-replay --map=res://content/scene-maps/initial-properties-sample.scenemap.json
./tools/dev.sh verify-replay
```
